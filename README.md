# Wine Classification and Prediction Using Machine Learning

## Project Overview
This project implements six Machine Learning algorithms using the built-in Wine dataset from Scikit-learn.

## Dataset Information
- Dataset: Wine Dataset
- Source: Scikit-learn
- Total Samples: 178
- Total Features: 13
- Target Classes: 3

## Machine Learning Algorithms
1. Simple Linear Regression
2. Multiple Linear Regression
3. Decision Tree Classification
4. K-Nearest Neighbors (KNN)
5. Logistic Regression
6. K-Means Clustering

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Google Colab

## Evaluation Metrics
- Mean Squared Error (MSE)
- R² Score
- Accuracy Score
- Confusion Matrix
- Classification Report
- Silhouette Score
- Adjusted Rand Index

## Conclusion
In this project, six Machine Learning algorithms were implemented using the Wine dataset. Regression, classification and clustering techniques were applied to understand different Machine Learning approaches and evaluate their performance.
